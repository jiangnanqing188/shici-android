02 / 校验

核对后再安装

请从已知的 GitHub 仓库 jiangnanqing188/shici-android 打开对应设备的 HTTPS Release 页面，核对 APK 附件、文件大小和 SHA256SUMS.txt。

安装前请先在“设置 → 备份与恢复”导出学习数据备份。

运行要求

    已知问题与传输

    • 大幅滚屏后的再次划词仍待真机复验；若失败或没有笔迹，可先用手动输入查词。
    • 官网仍使用 HTTP，页面与链接可能被篡改，不能作为独立核验依据。请独立确认浏览器中的 GitHub HTTPS 地址及仓库名。
    • 旧版需手动下载对应安装包覆盖升级，不要卸载。2.9.0 起可在应用内检查后续更新；仍是测试版，未在应用商店发布。
