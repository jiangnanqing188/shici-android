## 已确认的学习内容阻断项

| 编号 | 词项 / 字段 | 固定候选中的情况 | 对照事实与影响 |
|---|---|---|---|
| DQ-001 | `approach.translation` | 名词部分只列接近、入门；动词部分列接近、近似、商量 | 牛津学习词典首个名词义项对应处理问题的方法 / 方式；该常见阅读义项缺失，不适合作为完整常用义项学习资料 |
| DQ-002 | `data.translation` | 数据释义中混入显示或设置系统日期的 DOS 命令说明 | 微软官方文档对应的命令是 `DATE`；这是词项内容串入，不是用户查词速度问题 |
| DQ-003 | `children.exchange` | 包含 `s:childrens` | `children` 已是 `child` 的复数，不应再把追加 s 的形式作为标准复数教学 |
| DQ-004 | `men.exchange` | 包含 `s:mens` 和 `3:mens` | `men` 是 `man` 的复数；该映射不应直接作为标准名词复数或动词三单 |
| DQ-005 | `women.exchange` | 包含 `s:womens` 和 `3:womens` | `women` 是 `woman` 的复数；无撇号的追加 s 不能当作标准复数映射 |

上述结论针对准确字段及标准英语学习用途。其他语言词条、专名、所有格或非标准写法可能在语料中出现，不意味着这些映射可自动作为该英语词的标准词形。尤其不能粗暴“只要源数据写了就接受”。

## 映射完整性提示：不要扩大成不存在词条

- `be.exchange` 仅列 `was/is/been/being`，没有覆盖 `am/are/were` 的全部形式。British Council 的基础语法材料列出这些形式。**这只是当前字段不完整**，不能据此声称完整库不能查询 `were`；原库 `were` 另有 `0:be` 逆向映射。
- `lie.translation` 合并躺、说谎等义项，正向 `exchange` 只列 `lay/lain` 一组，没有 `lied` 一组。牛津将这两个动词分开，分别对应两组过去式。**不能声称原库没有 `lied`**：原库 `lied` 实际有 `0:lie` 映射，但其精确释义指德国歌曲，单纯优先显示精确词条也可能让学习者误解。
- 后续实现必须核对正向变形与逆向 lemma，并处理同形异义；不能用删后缀或盲目选唯一词头代替。

  --csv .tools/dictionaries/ecdict/ecdict.csv \
