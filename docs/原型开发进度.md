## 用户醒来后的建议测试顺序

本轮未执行安装。由用户确认安装后再按顺序检查：

1. 不开悬浮窗，检查四个栏目能否打开，初始计数是否为 0。
2. 设置中查询 `evidence`、`studies`，检查生词记录、笔记、掌握、统计；查询 `saw` 应要求确认词头，`unknownword` 应提示未收录。
3. 返回首页开启悬浮查词，核对全屏授权说明，再去海文有对应演示词的题目或自备英文测试页框选。
4. 分别取消、关闭释义卡片、关闭整个悬浮开关，检查是否误点答案、是否残留浮层。
5. 检查重启后的记录和 PDF 字体、分页。正式大量记录前先解决备份能力。
6. 如流程成立，再采集真实耗时和识别数据，不能用肉眼感觉替代速度报告。
