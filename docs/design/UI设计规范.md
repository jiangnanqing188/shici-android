# 拾词 · UI 设计规范

日期：2026-10-08。工作名称“拾词”可后续修改，不代表商标或最终命名。

## 方向
面向备考学生的安静学习工具，不是营销网站或数据大屏。采用纸张般的暖白背景、墨色正文、单一深青绿操作色。优先阅读和明确的开关状态，拒绝巨大装饰插画、渐变、毛玻璃和密集卡片矩阵。

## 色彩与尺寸
- 背景 #F6F5F0；表面 #FFFFFF；正文 #242F2C；次要文字 #68736D。
- 主色 #276552；淡主色 #E7F0EB；细分隔线 #DFE4DC。
- 警示 #8A5923，错误 #AD3E36，必须同时有文字提示。
- 中文使用系统 sans-serif，英文词头可使用系统 serif；正文至少 16sp，按钮至少 48dp 触摸范围。
- 间距 4/8/12/16/24/32dp。主面板圆角 16dp，小控件 8dp。以留白与细边界分层，不用重阴影。

## 布局
平板横屏建议左侧约 176–200dp 的轻导航区，右侧主内容。窄屏自动使用顶部标题与底部四项导航，不能挤压固定宽度双栏。
导航四项：首页、生词本、统计、设置。没有账号、排行榜和虚假联网状态。

### 首页
- 小字“专注阅读，随手拾词”，主标题“让生词停在这里”。
- 主功能区域标题“悬浮查词”，右侧显眼的开关；下面以文本明确显示已关闭 / 准备中 / 已开启 / 错误。
- 关闭时说明“开启后，可在题目页面框选查词”；准备期间禁用重复开启，但允许停止。
- 一行轻量的今日查询、今日新增数据，来自真实本地记录，初次使用显示 0。
- 最近生词采用列表，不堆砌卡片；空态写“查到的第一个单词，会留在这里”。
- 简短提示“打开悬浮查词 → 回到题目 → 框选单词”。演示词库标识必须醒目而不干扰。

### 生词本
- 顶部标题与“导出 PDF”按钮；支持搜索。
- 宽屏左侧词条列表、右侧词条详情；资源不足时可以单列详情弹窗，不能牺牲操作可用性。
- 词条正文展示原词形、词头、词性、中文、来源、“演示词库”标识、查询次数与日期；笔记和已掌握操作明确。
- 空态不能填假数据。为了验证流程，可在设置放明确的“演示查词”输入入口，成功查询后才生成真实记录。

### 统计
真实聚合的查询次数、新增数、待复习/已掌握；避免伪造趋势图和硬编码增长率。

### 设置
词库来源、版本及原型限制；权限说明；备份恢复能力按实际完成状态展示。未实现的功能不做可点击假按钮。

### 悬浮交互
- 小型深青绿按钮，以易懂图标或“词”字表达，支持拖动。
- 框选层顶部“框选要查的单词”，明确取消按钮。原页面截图只是临时背景。
- 释义卡片用白底、深色英文词头、简短中文、来源和保存状态。提供关闭和纠错，待保存不能显示已保存。
- 关闭释义卡片保留查词会话；主开关/通知停止才结束。

## 图像参考与实现
图像模型生成物用于布局和视觉参考，不作为整个 UI 的替代。图中示例词与数字必须在实现中替换为真实数据/空态。原生控件的可访问性、文字缩放与开关真实状态优先于像素复刻。

## 参考图与实现裁决

设计图：`ui-concept.png`（本地参考图，未纳入源码提交）。

图像生成记录：按用户要求尝试 GPT-Image-2.5 xhigh 代理，接口返回该模型不支持 Responses；随后通过专用图像生成工具完成。专用工具未暴露模型与推理档位，因此不能声称本图已经确认由指定 xhigh 配置生成。

采纳图中的纸白背景、轻导航、开关功能区、英文词头层级与列表详情布局。以下由设计负责人裁决，不照搬生成图的额外内容：
- 导航名称统一为“生词本”，不沿用生成图中的名称误写或别名。
- 首轮不做发音按钮、额外例句与三档熟练度；掌握状态使用明确的已掌握/待复习。
- 查词自动记录，不同时展示“已收录”与“加入生词本”两个矛盾入口。
- 所有示例词、日期和数字都不作为默认真实数据。初始记录为空。
- 主界面必须适配字体放大和窄窗口；布局允许合理变化，不追求静态图像的绝对像素。

## 2026-10-09 荧光笔原型增补（开发中）

首页与二级页的既有图、暖纸白/青绿视觉保持不变；本轮仅替换选择手势，不重做原图。领域元素是题目文本、荧光笔、纸面划记、词头与生词笔记；半透明黄色笔迹表达“已涂到”，深青绿完成按钮表达提交。拒绝整块矩形全选、等待OCR后才出笔迹和未实现的译句按钮。

- 在静态截图上涂划，允许抬笔换行、多笔累积；抬笔之间不连接，避免把跨行移动误算选区。
- 工具栏提供完成划选、重画、取消；笔迹反馈即时，完成后才启动识别。这个明确完成动作是原型取舍，不能把完成后耗时当作原来的松手耗时。
- 单词按词级位置与笔迹命中选取，不按所有笔迹外接矩形全选。短轻点不查词；空白不入库。
- 多词结果保留阅读顺序、大小写和标点，可选择一个词查词、纠正或重选；译句服务未接入，不默认联网或上传截图。
- 最终参数、自动测试及设备样本在本轮工作记录中登记；真实手写笔、字号、海文页面和准确率仍分项验收。
