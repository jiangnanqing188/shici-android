# 五类考试官方考纲核查

日期：2026-10-09（Asia/Shanghai）。状态：**五个 Luna High 的官方来源核查已完成；四、六级完整官方PDF已取得，但五类机读逐词基准均未获验证，未执行考纲覆盖比较。**

## 目标与验证边界

用户在完成备考词书统计后要求“去考纲查”，并要求再分五个代理、全部使用 Luna High。本轮分别核查考研英语（一）/（二）、大学英语四级、大学英语六级、英语专业四级、英语专业八级。主线程汇总出处、版次、获取程度和可比较的范围。

步骤 → 验证方法：

1. 官方来源与版次 → 核对考试机构、命题机构、官方出版社或明确的高校原文来源，区分发布时间、适用年份和URL日期。
2. 大纲内容与附录 → 区分“词汇量要求”“完整逐词附录”和“样题/考试结构”；不得用教学大纲、培训词书或资料站替代考试大纲。
3. 完整词表与当前候选比对 → 仅对获取完整原文、固定哈希、逐词提取且验证无歧义的基准计算覆盖/缺失/额外收录；否则标记未执行，不从约数推导缺词数。
4. 汇总与本地交付 → 保留来源证据和未解决项，不修改现有12,785词头候选，不把待核查标签升成官方认定。

- 按下载原件核定：词表说明在**物理页20 / 纸面页15**；实际词头从**物理页21 / 纸面页16**（a/an）开始，到**物理页149 / 纸面页144**（★zoom）结束。主线程用 `pdfinfo`、页面文字和渲染检查了说明页/首词页；六级代理此前混用页码已纠正。
