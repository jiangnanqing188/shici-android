## “原始状态”的具体含义

1. 仅对词头做 NFC、小写、弯撇号和空白规范化；不删后缀，不推断词根，不凭模型造义。
2. 同一词头汇总五书所有原始 `(pos, meaning)`；只去除完全相同的二元组，不合并不同义项。展示顺序为考研、四级、六级、专四、专八；原始中文与词性原样保留，仅增加词性展示标记和换行。
3. 原词库没有词形映射：`alias_count=0`。不使用旧演示映射、不接入 ECDICT 映射，不把不存在的变形自动猜成词头；未收录不产生学习事件。
4. 所有新词库记录保持 `content_review_status=unreviewed`；既有 supported、unresolved 和修订候选均不改变此次词库。
5. 运行时验证文件 SHA256、格式版本、来源版本、条目数量、非空义项与重复词头。检查失败明确提示，不回退到演示或在线生成。
6. 新查询保存实际词库来源和版本；升级不批量重写历史学习记录。旧记录仍保留原词源；再次成功查询才更新该词释义快照，同时保留笔记、掌握状态和历史事件。重复回调不能刷新快照或双计。

## 构建与恢复

从项目根目录使用既有工具；输出目录必须不存在，已有目录改用新的明确名称，不覆盖历史候选：

```bash
python3 -B tools/dictionary/build_kajweb_app.py \
  --manifest docs/dictionary/source-inventory-20261009.json \
  --source-dir .tools/dictionaries/source-review-20261009 \
  --output-dir .tools/dictionaries/kajweb-app-raw-20261010
mkdir -p app/src/main/assets/dictionary
cp .tools/dictionaries/kajweb-app-raw-20261010/assets/dictionary/kajweb.tsv.gz \
   app/src/main/assets/dictionary/kajweb.tsv.bin
cp .tools/dictionaries/kajweb-app-raw-20261010/assets/dictionary/kajweb-manifest.json \
   app/src/main/assets/dictionary/kajweb-manifest.json
```
